# Codicons（VS Code アイコン）

サイドバーツリーのヘッダー操作ボタン（新しいファイル / 新しいフォルダー / 最新の情報に更新 /
すべて折りたたむ / アクティブ ドキュメントとの同期）のパスデータは
[vscode-codicons](https://github.com/microsoft/vscode-codicons) の
`new-file` / `new-folder` / `refresh` / `collapse-all` / `go-to-file`（`src/icons/*.svg`）を
そのまま埋め込んだもの。
