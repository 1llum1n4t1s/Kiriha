# Kiriha

Chrome ライクな見た目のタブ型ファイラー（Windows 用）。エクスプローラーと同じ操作感のまま、垂直タブ・お気に入りバー・フォルダーツリーで快適にファイル管理できます。画像・動画をそのまま大きく見られるギャラリー表示も備えています。

## インストール

1. [Kiriha 公式サイト](https://kiriha.kagayoi.com/) からインストーラーをダウンロードして実行します。
2. スタートメニューとデスクトップに Kiriha のショートカットが作成されます。
3. 以後の更新は自動です（起動時と 6 時間おきにチェック、「… > 更新の確認」で手動チェックも可能）。新バージョンはダイアログからダウンロード・適用・再起動まで完結し、「このバージョンをスキップ」も選べます。

動作環境は Windows 10 バージョン 1809 以降（x64 / ARM64）です。バージョンごとの変更点は [CHANGELOG.md](CHANGELOG.md) を参照してください。

## 主な機能

### タブとナビゲーション

- **垂直タブ**: `＋` で新規タブ、`✕` で閉じる。右クリックから複製・固定・一括クローズなどのタブ操作。固定タブはその階層を維持し、移動先は新しいタブで開きます。タブはドラッグで並べ替えでき、フォルダーをタブバーへドロップすると新しいタブで開きます。ドラッグ中にタブへ 1 秒重ねるとそのタブへ切り替わるので、別のタブで開いているフォルダーへも落とせます
- **アドレスバー**: Web ブラウザと同じく現在のパスを文字で表示。クリックでそのまま直接入力へ切り替え（Esc で戻る）、「PC」でドライブ一覧
- **ステータスバーのパンくずリスト**: ウィンドウ下部にパンくずリストを表示。各階層のクリックで移動、「›」からサブフォルダーへ移動できます。幅に収まらないときはエクスプローラーと同じく浅い階層側から畳まれ、左端の「…」から開けます
- **左ペイン**: Windows 標準のクイックアクセスと PC / ドライブを表示。「ツリー表示」トグルでフォルダーツリーに切り替わります。ツリーの上には VSCode と同じ 4 つのボタン（新しいファイル / 新しいフォルダー / 最新の情報に更新 / すべて折りたたむ）と、Visual Studio と同じ「アクティブ ドキュメントとの同期」トグル（オンの間は現在のフォルダーへ自動追従、既定オン）があります。新規作成はツリー内の入力欄で名前を付けます（「a/b/c.txt」のような入力で中間フォルダーごと作成）。ツールバーのボタンで左ペイン自体の表示 / 非表示も可能
- **お気に入りバー**: Ctrl+Shift+B で表示切替。ドラッグ & ドロップで登録、フォルダー分け・名前変更・並べ替えなど Chrome と同じ右クリックメニュー

### ファイル操作

- **エクスプローラー完全互換**: 切り取り / コピー / 貼り付け（Ctrl+X/C/V、エクスプローラーとクリップボード相互運用）、削除はごみ箱へ（進捗ダイアログ付き）、F2 で名前の変更。Ctrl+Z で削除を取り消せます
- **右クリックメニュー**: Windows 標準のシェルコンテキストメニューがそのまま動作（コピー / 削除 / プロパティ、拡張機能が追加した項目も含む）。設定から Windows 11 風の Kiriha 独自メニューにも切り替えられます。フォルダーには「エクスプローラーで開く」も表示されます
- **ドラッグ & ドロップ**: エクスプローラーとの相互 DnD。同一ドライブ = 移動 / 別ドライブ = コピー（Ctrl でコピー、Shift で移動を強制）。右ボタンでドラッグすると、ドロップ時に「ここにコピー / ここに移動 / ショートカットをここに作成」を選べます。ドロップ先はプレビューで確認できます
- **新規作成**: エクスプローラーと同じ「新規作成」メニュー（インストール済みアプリの項目も表示）
- **共有**: ファイルを選択してツールバーの「共有」ボタンを押すと、Windows 標準の共有シート（近距離共有・メール・対応アプリへの送信）が開きます
- **パスのコピー**: アドレスバー右の「選択のパスをコピー」ボタンで、選択中の項目のフルパスをクリップボードへ。現在のフォルダーのパスはアドレスバーを右クリック →「アドレスのコピー」
- **自動更新**: フォルダー内の変更（追加・削除・名前変更）は自動で一覧へ反映されます

### 表示とカスタマイズ

- **表示モード**: 詳細 / 一覧 / 並べて表示 / アイコン（特大〜小、なめらかにサイズ変更可能）。表示種別・アイコンサイズ・並べ替え・列幅はフォルダーごとに記憶されます。記憶していないフォルダーの既定は設定から指定できます
- **並べて表示**: エクスプローラーと同じタイル表示。48px のアイコンやサムネイルの右に、名前・種類・サイズを並べます（名前が 2 行になったときはサイズを省略します）
- **詳細表示**: 列ヘッダークリックでソート、右クリックで列の表示 / 非表示（作成日時列あり）、境界ドラッグで幅変更。横スクロールにも対応。コンパクトビュー（全タブ共通）も選べます
- **サムネイル**: アイコン表示で画像・動画・PDF・RAW のサムネイルを表示（JXL / AVIF / HEIC にも対応）。ドライブには使用率バーを表示
- **アイコンセット**: 設定から 3 種類を選択 — 絵文字 / [Material Icon Theme](https://github.com/material-extensions/vscode-material-icon-theme) の拡張子別カラーアイコン / エクスプローラーと同じ Windows 標準アイコン
- **テーマ**: Windows のダーク / ライト設定とアクセントカラーに自動追従（変更即反映）。システム / ライト / ダーク / One Dark / Dim から選択でき、アクリル効果（半透明ぼかし）の ON/OFF も可能
- **プレビューペイン**: Alt+P で画像 / テキスト / フォルダー情報（項目数・合計サイズ）をプレビュー
- **ステータスバー**: 項目数 / 選択数と合計サイズ（フォルダーは中身も集計）/ 1 件だけ選んでいるときはその更新日時を表示

### ギャラリー表示

写真や動画をアプリの中で大きく見るためのモードです。アイコン表示のサイズスライダーを一番右まで上げるか、画像 / 動画をダブルクリックすると切り替わります（ダブルクリックでの動作は設定で変更でき、Windows の関連付けは変更しません）。

- **1 枚表示 + フィルムストリップ**: 下部のサムネイル帯から選択。帯の高さは境界ドラッグで変えられます
- **前後の送り**: ホイール、← / →、左右端の大きなボタン。全画面で動画を見ているときは Ctrl+← / Ctrl+→ を使います
- **情報パネル**: 選択中の画像の種類・寸法・サイズ・撮影日時・カメラ・レンズ・F 値・露出・ISO などを左側に表示
- **拡大と移動**: コントロールバーのスライダーまたは Ctrl+ホイールで拡大、ドラッグで移動。100% ボタンで等倍に戻ります
- **回転**: JPEG / TIFF / PNG は画質を落とさずに回転して保存します。動画は表示だけを回転し、ファイルは書き換えません
- **動画再生**: 再生 / 一時停止・シーク・音量・ミュート・ループ・再生速度に対応（音量と速度は保存されます）
- **鮮鋭化とガンマ補正**: 画面に合わせて拡大したときのぼけを抑えます（設定 > 表示 で ON/OFF と強さを選択）。ギャラリー中の ↑ / ↓ で明るさ（ガンマ）を調整できます
- **全画面**: F11 またはコントロールバーのボタン。Esc は全画面 → ギャラリー → 通常表示と 1 段ずつ戻ります

### 検索と表示言語

- **検索**: 検索ボックスに入力するだけでサブフォルダーを含めて検索（Ctrl+F でフォーカス、Esc でクリア）
- **17 言語対応**: 日本語・英語・中国語（簡体 / 繁体）・韓国語・ドイツ語・スペイン語・フランス語・イタリア語・ポルトガル語（ブラジル）・ロシア語・ウクライナ語・インドネシア語・フィリピン語・タミル語・サンスクリット語・ラテン語。初回は Windows の表示言語から自動で選ばれ、設定のドロップダウンで再起動なしに切り替えられます

## 設定

ツールバーの歯車ボタンまたは左ペイン下部の「設定」から、同一ウィンドウ内の設定タブが開きます。

- 起動時に開くフォルダー / 前回のタブを復元 / タスクトレイ格納
- テーマ・アクリル効果・アイコンセット・表示言語
- フォルダーの既定表示と、フォルダーごとの表示設定のリセット
- 右クリックメニューの方式、マウス操作（ダブルクリック / ホイールクリック）の割り当て
- 隠しファイル / 拡張子 / チェックボックスの表示
- ギャラリー表示（鮮鋭化、画像・動画をダブルクリックしたときの動作）
- Windows 統合（スタートアップ登録、エクスプローラーの右クリックに「Kiriha で開く」、フォルダーを開く既定のアプリ）
- キーボードショートカット一覧の確認
- 更新の確認とライセンス・バージョン情報

ウィンドウ位置・サイズ・タブ・お気に入り・表示設定は自動で保存されます。

## 主なキーボードショートカット

| 操作 | キー |
|---|---|
| 新しいタブ / タブを閉じる / 閉じたタブを開く | Ctrl+T / Ctrl+W / Ctrl+Shift+T |
| タブの切り替え | Ctrl+Tab、Ctrl+1〜9、Ctrl+PgUp/PgDn |
| アドレスバーへ移動 | Ctrl+L または F4 |
| 検索 | Ctrl+F または F3 |
| 戻る / 進む / 1 つ上へ | Alt+← / Alt+→ / Alt+↑ |
| 更新 | F5 |
| 名前の変更 / 削除 / 完全削除 | F2 / Delete / Shift+Delete |
| 削除を元に戻す | Ctrl+Z |
| お気に入りに追加 / お気に入りバー表示 | Ctrl+D / Ctrl+Shift+B |
| プロパティ / プレビューペイン | Alt+Enter / Alt+P |
| 全画面 / アイコンサイズのリセット | F11 / Ctrl+0 |
| ギャラリー: 前後の送り / 明るさ / 終了 | ← → （または Ctrl+← →）/ ↑ ↓ / Esc |

このほかの主要なショートカットは設定タブの「ショートカット」で確認できます。マウスの戻る / 進むボタン、タブの中クリック閉じにも対応しています。

## 購入とライセンス認証

- **無料試用**: インストールから 14 日間はすべての機能を無料で利用できます
- **購入（¥1,980 買い切り）**: 試用期間が終了するとロック画面が表示されます。「購入ページを開く」から決済すると、その場で利用できるようになります
- **別の PC で使う / 再認証する**: ロック画面または「設定 > 更新と情報 > ライセンス」で購入時のメールアドレスを入力すると確認コードが届きます。6 桁のコードを入力すれば認証完了です（アカウント登録・パスワードは不要）。ライセンスキーを控えている場合は「ライセンスキーを直接入力する」からも認証できます
- **台数制限はありません**: 1 回の購入で、お使いの PC すべてにインストールできます
- **認証の解除**: 「設定 > 更新と情報 > ライセンス」の「ライセンス認証を解除」でその PC の認証だけを外せます。購入は有効なままなので、同じメールアドレスでいつでも認証し直せます

## トラブルシューティング

- **更新が来ない**: 「… > 更新の確認」で手動チェックできます。プロキシ環境などでダウンロードに失敗する場合は、[公式サイト](https://kiriha.kagayoi.com/) から最新のインストーラーを直接実行しても設定は引き継がれます
- **右クリックメニューの表示がおかしい**: 「設定 > 表示 > 右クリックメニュー」で「Windows 標準」など他の方式に切り替えてください。特定のシェル拡張が原因のことがあります
- **表示がおかしい / 動作が不安定**: 設定タブの「設定をリセット」で表示設定を初期状態に戻せます。フォルダーごとの表示だけを戻したいときは「フォルダーごとの表示設定をリセット」を使ってください
- **問題の報告**: ログは `%LocalAppData%\Kiriha\logs` に保存されています（「設定 > メンテナンス > ログフォルダーを開く」からも開けます）。不具合報告の際に添付いただくと調査がスムーズです
